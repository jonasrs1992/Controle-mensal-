CONTROLE MENSAL — PWA

Arquivos principais:
- index.html
- manifest.webmanifest
- service-worker.js
- ícones PNG

IMPORTANTE:
Para aparecer a opção de instalar no navegador, o PWA precisa ser aberto por um endereço HTTPS
(ou localhost durante testes). Abrir apenas o arquivo index.html pelo gerenciador de arquivos não
ativa a instalação PWA nem o Service Worker.

Como publicar:
1. Envie TODOS os arquivos desta pasta para uma hospedagem HTTPS.
2. Abra o endereço no Google Chrome do Android.
3. Use o botão "Instalar aplicativo" quando aparecer, ou Menu > Adicionar à tela inicial / Instalar app.
4. Depois da primeira abertura, o aplicativo funciona offline.

Os dados são armazenados localmente no navegador/aplicativo do aparelho.
